PostgreSQL Tutorial for Beginners 🐘

Important: PostgreSQL browser me direct nahi chalta. Ye relational database hai. Niche "Simulate" se mock output dekho ya "DB Fiddle" pe real query chalao.

Lesson 1: CREATE TABLE

PostgreSQL me table banane ke liye CREATE TABLE use karo. Data types define karne padte hai.

CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  age INT,
  email VARCHAR(255) UNIQUE,
  created_at TIMESTAMP DEFAULT NOW()
);

Lesson 2: INSERT Data

INSERT INTO se data add karo. RETURNING se inserted row wapas milegi.

INSERT INTO users (name, age, email)
VALUES
  ('Pawan', 20, 'pawan@example.com'),
  ('Rahul', 22, 'rahul@example.com')
RETURNING *;

Lesson 3: SELECT Query

SELECT se data fetch karo. WHERE, ORDER BY, LIMIT use kar sakte ho.

-- Sab users
SELECT * FROM users;

-- Filter ke saath
SELECT name, age FROM users
WHERE age > 18
ORDER BY age DESC
LIMIT 5;

Lesson 4: UPDATE & DELETE

UPDATE se data change karo, DELETE se hatao. WHERE zaruri hai warna sab update ho jayega.

-- Update
UPDATE users
SET age = 21, city = 'Mumbai'
WHERE name = 'Pawan';

-- Delete
DELETE FROM users
WHERE age < 18;

Lesson 5: JOIN Tables

PostgreSQL ka power: Multiple tables ko join karo. INNER JOIN, LEFT JOIN sab hai.

-- Orders table
CREATE TABLE orders (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  product VARCHAR(100),
  amount DECIMAL(10,2)
);

-- Join query
SELECT
  u.name,
  o.product,
  o.amount
FROM users u
INNER JOIN orders o ON u.id = o.user_id
WHERE o.amount > 1000;

Lesson 6: Advanced Features

PostgreSQL me JSONB, Arrays, Window Functions jaise features hai.

-- JSONB column
CREATE TABLE profiles (
  id SERIAL PRIMARY KEY,
  data JSONB
);

INSERT INTO profiles (data) VALUES
  ('{"skills": ["SQL", "Python"], "level": "advanced"}');

-- Query JSON
SELECT data->>'level' FROM profiles WHERE data @> '{"skills": ["SQL"]}';

-- Window function
SELECT name, age,
  RANK() OVER (ORDER BY age DESC) as age_rank
FROM users;
