1. What is Python?

Python is a powerful, high-level, and easy-to-learn programming language. It is widely used in web development, AI, machine learning, automation, data science, cybersecurity, and app development.

Easy to Learn

Python syntax is simple and beginner friendly.

Popular

Used by companies like Google, Netflix, and Instagram.

Powerful

Supports AI, web apps, automation, and much more.

9. Object Oriented Programming (OOP)

class Student:
def __init__(self, name):
    self.name = name

def show(self):
    print("Student Name:", self.name)

s1 = Student("Pawan") s1.show()

OOP Concepts

  • Class
  • Object
  • Inheritance
  • Polymorphism
  • Encapsulation
  • Abstraction

18. Advanced Python Topics

List Comprehension

print(numbers)

Modules

print(math.sqrt(25))

Decorators

def decorator(func):
def wrapper():
    print("Before function")
    func()
return wrapper
