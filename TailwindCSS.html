  <div class="min-h-screen bg-gradient-to-br from-blue-500 to-purple-600 flex items-center justify-center p-4">

  </div>
</body>
</html>

Lesson 3: Hover, Focus & Dark Mode

hover:, focus:, dark: modifiers se states handle karo.

<!DOCTYPE html>
<html class="dark">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = { darkMode: 'class' }
  </script>
</head>
<body class="bg-white dark:bg-gray-900 min-h-screen p-8 transition-colors duration-300">
  <div class="max-w-md mx-auto">
    <h1 class="text-3xl font-bold text-gray-900 dark:text-white mb-6">Dark Mode Demo</h1>

    <button class="bg-purple-500 hover:bg-purple-600 active:bg-purple-700 focus:ring-4 focus:ring-purple-300 text-white font-medium py-3 px-6 rounded-lg transition-all duration-200 w-full mb-4">
      Hover & Click Me
    </button>

    <input type="text" placeholder="Focus me" class="w-full px-4 py-3 border-2 border-gray-300 dark:border-gray-600 rounded-lg focus:border-blue-500 focus:ring-2 focus:ring-blue-200 dark:bg-gray-800 dark:text-white outline-none transition">

    <div class="mt-6 p-4 bg-gradient-to-r from-pink-500 to-orange-500 rounded-lg text-white">
      <p class="font-semibold">Gradient + Dark Mode Support</p>
      <p class="text-sm opacity-90">Resize window to see responsive behavior</p>
    </div>
  </div>
</body>
</html>
