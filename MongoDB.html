MongoDB Tutorial for Beginners 🍃

Important: MongoDB browser me direct nahi chalta. Ye NoSQL database hai. Niche "Simulate" se mock output dekho ya "Playground" pe real query chalao.

Lesson 1: Insert Document

MongoDB me data JSON jese documents me store hota hai. insertOne() se ek record add karo.

db.users.insertOne({
  name: "Pawan",
  age: 20,
  city: "Delhi",
  skills: ["JavaScript", "Python"]
})

Lesson 2: Find Documents

find() se data search karo. Filter object pass kar sakte ho.

// Sab users
db.users.find()

// Filter ke saath
db.users.find({ age: { $gt: 18 } })

// Sirf ek field
db.users.find({}, { name: 1, _id: 0 })

Lesson 3: Update Document

updateOne() ya updateMany() se data change karo. $set operator use hota hai.

db.users.updateOne(
  { name: "Pawan" },
  { $set: { age: 21, city: "Mumbai" } }
)

// Array me add karo
db.users.updateOne(
  { name: "Pawan" },
  { $push: { skills: "Node.js" } }
)

Lesson 4: Delete Document

deleteOne() ya deleteMany() se record hatao.

db.users.deleteOne({ name: "Pawan" })

// Multiple delete
db.users.deleteMany({ age: { $lt: 18 } })

Lesson 5: Aggregation Pipeline

MongoDB ka sabse powerful feature. Data ko group, filter, sort karo.

db.users.aggregate([
  { $match: { age: { $gte: 18 } } },
  { $group: {
      _id: "$city",
      totalUsers: { $sum: 1 },
      avgAge: { $avg: "$age" }
  }},
  { $sort: { totalUsers: -1 } }
])
