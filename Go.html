Introduction to Go

Go (also called Golang) is an open-source programming language created at Google by Robert Griesemer, Rob Pike, and Ken Thompson in 2009. It compiles to a single native binary — no runtime, no VM, no dependencies.

Go was designed to solve real engineering problems: slow builds, complex dependency management, and difficulty writing concurrent programs. It intentionally keeps the language small and readable.

⚡
Fast Compilation
Compiles to native binary in seconds, even for large projects.
🔀

Goroutines and channels make concurrent code simple and safe.
📦

Ships as one self-contained executable. No runtime needed.
🧹

25 keywords. Opinionated formatting with gofmt.

go run main.go

go build -o myapp .

# Format code (always run this!)
gofmt -w .

# Run all tests

package main

func main() {

}
Key Convention Every Go program starts in package main and execution begins in the main() function. Go enforces that every imported package must be used — unused imports are compile errors.

Variables & Basic Types

Go is statically typed — every variable has a fixed type known at compile time. Types can often be inferred automatically.

// Explicit declaration with var
var name   string  = "Alice"
var age    int     = 30
var active bool    = true
var score  float64 = 98.5

// Short declaration (inside functions only)
city    := "Tokyo"    // inferred: string
count   := 42         // inferred: int
pi      := 3.14159   // inferred: float64

// Multiple assignment
x, y, z := 1, 2, 3

// Constants
const MaxRetries = 5
const AppName   = "MyApp"

// iota — auto-incrementing constants
const (
    Sunday = iota  // 0
    Monday           // 1
    Tuesday          // 2
)

Control Flow

If / Else

// Standard if-else
if age >= 18 {
    fmt.Println("Adult")
} else if age >= 13 {
    fmt.Println("Teen")
} else {
    fmt.Println("Child")
}

// If with init statement (scoped variable)
if err := doSomething(); err != nil {
    fmt.Println("Error:", err)
}

For Loop

// Go has only one loop keyword: for

// Classic C-style loop
for i := 0; i < 5; i++ {
    fmt.Println(i)
}

// While-style loop
n := 1
for n < 100 {
    n *= 2
}

// Infinite loop
for {
    // use break to exit
}

// Range loop (index, value)
nums := []int{10, 20, 30}
for i, v := range nums {
    fmt.Printf("index=%d val=%d\n", i, v)
}

// Range over map
for key, value := range myMap {
    fmt.Println(key, value)
}

Switch

// No need for break — cases don't fall through by default
switch day {
case "Mon", "Tue", "Wed", "Thu", "Fri":
    fmt.Println("Weekday")
case "Sat", "Sun":
    fmt.Println("Weekend")
default:
    fmt.Println("Unknown")
}

// Switch without expression (acts like if-else)
switch {
case score >= 90: fmt.Println("A")
case score >= 80: fmt.Println("B")
default:          fmt.Println("C")
}

Arrays & Slices

Arrays have a fixed size. Slices are flexible, dynamic views into arrays — they are the idiomatic way to work with lists in Go.

// Array — fixed length, part of the type
var arr [3]int = [3]int{1, 2, 3}
arr[0] = 10
fmt.Println(len(arr)) // → 3

// Slice — dynamic length
s := []string{"a", "b", "c"}
s = append(s, "d")       // add element
fmt.Println(s[1:3])      // → [b c] (slicing)

// Make — allocate a slice with length and capacity
nums := make([]int, 5, 10)  // len=5, cap=10

// 2D slice
matrix := [][]int{
    {1, 2, 3},
    {4, 5, 6},
}

// copy() — copy between slices
dst := make([]int, len(s))
copy(dst, s)
Slice vs Array Arrays are value types — copying an array copies all its data. Slices are reference types — they point to an underlying array. Use slices in almost all cases.
06

Maps

Maps are Go's built-in hash map / dictionary type. Keys must be comparable types.

// Create a map
ages := map[string]int{
    "Alice": 30,
    "Bob":   25,
}

// Make an empty map
scores := make(map[string]float64)

// Set and get
scores["Alice"] = 98.5
val := scores["Alice"]  // → 98.5

// Check if key exists
val, ok := ages["Charlie"]
if !ok {
    fmt.Println("Charlie not found")
}

// Delete a key
delete(ages, "Bob")

// Iterate over a map
for name, age := range ages {
    fmt.Printf("%s is %d years old\n", name, age)
}
Map Iteration Order Map iteration order is deliberately randomized in Go. Never rely on a specific order when ranging over a map.

Structs

Structs are Go's way of grouping related data. They are value types and support embedding for composition.

// Define a struct
type Person struct {
    Name  string
    Age   int
    Email string
}

// Create instances
alice := Person{Name: "Alice", Age: 30, Email: "alice@go.dev"}
bob   := Person{"Bob", 25, "bob@go.dev"}  // positional

// Access fields
fmt.Println(alice.Name)
alice.Age = 31

// Pointer to struct
p := &Person{Name: "Charlie", Age: 40}
p.Age = 41  // auto-dereferenced

// Anonymous struct
config := struct {
    Host string
    Port int
}{Host: "localhost", Port: 8080}

// Embedding (composition over inheritance)
type Employee struct {
    Person            // embedded — fields promoted
    Company string
}
emp := Employee{Person: alice, Company: "Google"}
fmt.Println(emp.Name)  // promoted from Person
08

Pointers

Go has pointers but no pointer arithmetic. They're used to share and mutate data across function boundaries.

// & gets the address, * dereferences
x := 42
p := &x          // p is *int, holds address of x
fmt.Println(*p)  // → 42 (dereference)
*p = 100         // modifies x through pointer
fmt.Println(x)   // → 100

// new() allocates a zeroed value and returns a pointer
n := new(int)    // *int pointing to 0

// Passing pointer to function (allows mutation)
func increment(n *int) {
    *n++
}
val := 5
increment(&val)
fmt.Println(val) // → 6

// Nil pointer
var ptr *string   // nil by default
if ptr != nil {
    fmt.Println(*ptr)
}

Functions

Functions in Go are first-class citizens. They support multiple return values — a key feature used for error handling.

// Basic function
func add(a, b int) int {
    return a + b
}

// Multiple return values
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("cannot divide by zero")
    }
    return a / b, nil
}
result, err := divide(10, 2)

// Named return values
func minMax(nums []int) (min, max int) {
    min, max = nums[0], nums[0]
    for _, v := range nums {
        if v < min { min = v }
        if v > max { max = v }
    }
    return  // naked return
}

// Variadic function
func sum(nums ...int) int {
    total := 0
    for _, n := range nums { total += n }
    return total
}
sum(1, 2, 3)   // → 6
sum(nums...)   // spread a slice

// Function as a value / closure
adder := func(x int) int { return x + 10 }
fmt.Println(adder(5)) // → 15

// defer — runs when surrounding function returns
func readFile() {
    f, _ := os.Open("file.txt")
    defer f.Close()  // always closes, even on panic
    // read file...
}

Methods

Methods are functions attached to a type via a receiver. Use a pointer receiver when you need to modify the receiver or it's large.

type Rectangle struct {
    Width, Height float64
}

// Value receiver — does NOT modify the struct
func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

// Pointer receiver — CAN modify the struct
func (r *Rectangle) Scale(factor float64) {
    r.Width  *= factor
    r.Height *= factor
}

// String() method — makes type printable
func (r Rectangle) String() string {
    return fmt.Sprintf("%.1fw × %.1fh", r.Width, r.Height)
}

rect := Rectangle{Width: 10, Height: 5}
fmt.Println(rect.Area())  // → 50
rect.Scale(2)
fmt.Println(rect)          // → 20.0w × 10.0h

Interfaces

Interfaces are satisfied implicitly in Go — no implements keyword. If a type has the required methods, it satisfies the interface.

// Define an interface
type Shape interface {
    Area()      float64
    Perimeter() float64
}

// Rectangle implicitly satisfies Shape
func (r Rectangle) Perimeter() float64 {
    return 2 * (r.Width + r.Height)
}

func printInfo(s Shape) {
    fmt.Printf("Area=%.1f Perimeter=%.1f\n", s.Area(), s.Perimeter())
}

// Empty interface — accepts any value
func printAny(v interface{}) {
    fmt.Println(v)
}
// Or with modern syntax:
func printAny(v any) { fmt.Println(v) }

// Type assertion
var i any = "hello"
s, ok := i.(string)  // ok=true, s="hello"

// Type switch
switch v := i.(type) {
case string:  fmt.Println("string:", v)
case int:     fmt.Println("int:", v)
default:      fmt.Println("unknown type")
}
Common Built-in Interfaces fmt.Stringer (String() string), error (Error() string), io.Reader (Read([]byte)), io.Writer (Write([]byte)), sort.Interface — these are everywhere in the standard library.

Error Handling

Go handles errors through explicit return values — there are no exceptions. The error type is a simple interface.

// error is just an interface: { Error() string }

// Return error from a function
func openFile(path string) (*os.File, error) {
    f, err := os.Open(path)
    if err != nil {
        return nil, fmt.Errorf("openFile: %w", err) // wrap error
    }
    return f, nil
}

// Create a custom error type
type ValidationError struct {
    Field   string
    Message string
}
func (e *ValidationError) Error() string {
    return fmt.Sprintf("%s: %s", e.Field, e.Message)
}

// errors.Is — check error type in chain
if errors.Is(err, os.ErrNotExist) {
    fmt.Println("File not found")
}

// errors.As — extract wrapped error type
var ve *ValidationError
if errors.As(err, &ve) {
    fmt.Println("Validation failed on field:", ve.Field)
}

// panic and recover (use sparingly)
defer func() {
    if r := recover(); r != nil {
        fmt.Println("Recovered:", r)
    }
}()
panic("something went very wrong")

Goroutines

A goroutine is a lightweight thread managed by the Go runtime. You can run thousands of them simultaneously — they use far less memory than OS threads.

// Launch a goroutine with the go keyword
func sayHello(name string) {
    fmt.Printf("Hello, %s!\n", name)
}

go sayHello("Alice")   // runs concurrently
go sayHello("Bob")

// Use WaitGroup to wait for goroutines
var wg sync.WaitGroup

for i := 0; i < 5; i++ {
    wg.Add(1)
    go func(id int) {
        defer wg.Done()
        fmt.Println("Worker", id)
    }(i)
}
wg.Wait()  // blocks until all Done() called

// Mutex — protect shared data
var mu sync.Mutex
counter := 0
mu.Lock()
counter++
mu.Unlock()

Channels

Channels are typed pipes for communication between goroutines. Go's motto: "Don't communicate by sharing memory; share memory by communicating."

// Create a channel
ch := make(chan int)        // unbuffered
buf := make(chan string, 5)  // buffered, capacity 5

// Send and receive
go func() {
    ch <- 42   // send (blocks until receiver ready)
}()
v := <-ch       // receive (blocks until value available)

// Directional channels
func producer(out chan<- int) { out <- 1 }   // send only
func consumer(in  <-chan int) { v := <-in }  // receive only

// Range over channel until closed
go func() {
    for i := 0; i < 3; i++ { ch <- i }
    close(ch)
}()
for v := range ch { fmt.Println(v) }

// Select — multiplex channels
select {
case msg1 := <-ch1: fmt.Println("ch1:", msg1)
case msg2 := <-ch2: fmt.Println("ch2:", msg2)
case <-time.After(1 * time.Second):
    fmt.Println("Timeout!")
default: fmt.Println("No channel ready")
}

Packages & Visibility

Go uses packages for code organization. Visibility is controlled by capitalization — Capitalized = exported (public), lowercase = unexported (private).

// ── mathutil/mathutil.go ──
package mathutil

// Exported — accessible outside this package
func Add(a, b int) int { return a + b }

// Unexported — only accessible inside this package
func helper(x int) int { return x * 2 }

// ── main.go ──
package main

import (
    "fmt"
    "math/rand"
    mu "github.com/myname/myapp/mathutil"  // alias
    _ "image/png"                            // blank import (side effects)
)

func main() {
    fmt.Println(mu.Add(2, 3))
}

Generics (Go 1.18+)

Go added generics in version 1.18 using type parameters. They allow writing reusable, type-safe code without using any.

// Generic function with constraint
func Map[T, U any](s []T, f func(T) U) []U {
    result := make([]U, len(s))
    for i, v := range s {
        result[i] = f(v)
    }
    return result
}

// Usage — type inferred automatically
doubled := Map([]int{1, 2, 3}, func(n int) int { return n * 2 })

// Type constraint — Number allows int or float64
type Number interface {
    int | int64 | float64
}

func Sum[T Number](nums []T) T {
    var total T
    for _, n := range nums { total += n }
    return total
}
Sum([]int{1,2,3})          // → 6 (int)
Sum([]float64{1.1, 2.2}) // → 3.3 (float64)

// Generic struct
type Stack[T any] struct {
    items []T
}
func (s *Stack[T]) Push(v T)  { s.items = append(s.items, v) }
func (s *Stack[T]) Pop() T {
    n := len(s.items) - 1
    v := s.items[n]
    s.items = s.items[:n]
    return v
}

go.mod — Module System

Go modules are the official dependency management system since Go 1.11. The go.mod file defines a module's identity and its dependencies.

# Initialize a new module
go mod init github.com/username/myapp

# Add a dependency
go get github.com/gin-gonic/gin@v1.9.1

# Download all dependencies
go mod download

# Remove unused dependencies
go mod tidy

# Show dependency graph
go mod graph
module github.com/username/myapp

go 1.22

require (
    github.com/gin-gonic/gin v1.9.1
    golang.org/x/sync        v0.6.0
)

require (
    // indirect dependencies managed automatically
    github.com/bytedance/sonic v1.9.1 // indirect
)
Commit go.sum Always commit both go.mod and go.sum to version control. The go.sum file contains cryptographic hashes for dependency verification and ensures reproducible builds.
