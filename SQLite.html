01

Introduction to SQLite

SQLite is an embedded relational database management system written in C.

Unlike MySQL or PostgreSQL, SQLite does not require a separate server process. The entire database is stored inside a single file.

Why SQLite Is Popular SQLite is extremely fast, lightweight, portable, and easy to deploy. It powers Android devices, iPhones, browsers, and many desktop applications.

02

Install & Setup

Install SQLite

# Ubuntu / Debian
sudo apt install sqlite3

# macOS
brew install sqlite

# Check version
sqlite3 --version

# Open or create database
sqlite3 mydatabase.db

Basic SQLite Commands

-- Show all databases
.databases

-- Show all tables
.tables

-- Show schema
.schema

-- Exit SQLite shell
.quit
03

Databases & SQL Basics

SQLite uses standard SQL syntax for creating and managing databases. 

-- Create database automatically by opening a file
sqlite3 school.db

-- Attach another database
ATTACH DATABASE 'backup.db' AS backup;
04

Creating Tables

Tables store structured data using rows and columns. 

CREATE TABLE students (

    id INTEGER PRIMARY KEY AUTOINCREMENT,

    name TEXT NOT NULL,

    age INTEGER,

    email TEXT UNIQUE,

    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
Data Type Description
INTEGER Whole numbers
REAL Floating-point numbers
TEXT String values
BLOB Binary data
NULL Empty value

06

Select Queries

The SELECT statement retrieves data from tables. 

-- Select all columns

SELECT * FROM students;

-- Select specific columns

SELECT name, age FROM students;

-- Order results

SELECT * FROM students
ORDER BY age DESC;

-- Limit results

SELECT * FROM students
LIMIT 5;
07

Update & Delete

-- Update rows

UPDATE students

SET age = 25

WHERE id = 1;

-- Delete rows

DELETE FROM students

WHERE id = 2;
Important Always use a WHERE clause in UPDATE or DELETE queries unless you intentionally want to modify all rows.
08

WHERE Clause & Filtering

SELECT * FROM students

WHERE age > 20;

SELECT * FROM students

WHERE name LIKE 'A%';

SELECT * FROM students

WHERE age BETWEEN 18 AND 25;
09

Joins

Joins combine data from multiple tables. 

SELECT

  students.name,

  courses.course_name

FROM students

INNER JOIN courses

ON students.id = courses.student_id;
10

Indexes

Indexes improve query performance by speeding up searches. 

-- Create index

CREATE INDEX idx_students_email

ON students(email);

-- Remove index

DROP INDEX idx_students_email;
11

Transactions

Transactions ensure database consistency. 

BEGIN TRANSACTION;

UPDATE accounts
SET balance = balance - 100
WHERE id = 1;

UPDATE accounts
SET balance = balance + 100
WHERE id = 2;

COMMIT;
12

Views

Views are virtual tables based on SQL queries. 

CREATE VIEW adult_students AS

SELECT name, age

FROM students

WHERE age >= 18;

SELECT

15

Best Practices

  • Use indexes on frequently searched columns.
  • Wrap related queries inside transactions.
  • Use parameterized queries to prevent SQL injection.
  • Backup database files regularly.
  • Normalize tables to reduce duplication.
  • Use WAL mode for better concurrency.
Performance Tip SQLite is excellent for local storage and medium-scale applications, but for very high concurrent write workloads, a client-server database may perform better.
