01

Introduction to Web Development

Every website you visit is built with three core technologies working together. HTML provides the content and structure, CSS controls visual presentation, and JavaScript adds interactivity and dynamic behaviour.

These are not separate worlds — they are designed to work in harmony. A browser parses all three and renders them into the page you see.

🏗️
HTML
HyperText Markup Language. Defines structure and meaning of content.
🎨
CSS
Cascading Style Sheets. Controls layout, colour, fonts, and animation.
⚡
JavaScript
Scripting language that makes pages interactive and dynamic.
🌐
Browser
Parses all three and renders the final visual result for users.
02

HTML Document Structure

Every HTML page follows a standard skeleton. The browser uses this structure to understand and render the document correctly.

<!-- Standard HTML5 document structure -->
<!DOCTYPE html>
<html lang="en">

  <head>
    <meta charset="UTF-8"/>
    <meta name="viewport" content="width=device-width, initial-scale=1.0"/>
    <title>My Page</title>
    <link rel="stylesheet" href="styles.css"/>
  </head>

  <body>
    <h1>Hello, World!</h1>
    <p>This is a paragraph.</p>
    <script src="script.js"></script>
  </body>

</html>
The <head> vs <body> The <head> contains metadata (invisible to users): charset, title, stylesheets, and scripts. The <body> contains all visible page content.

HTML Attributes

Attributes provide additional information about HTML elements. They are placed inside the opening tag as name="value" pairs.

<!-- Global attributes — work on any element -->
<div
  id="unique-id"           <!-- unique on the page -->
  class="card featured"    <!-- one or more CSS classes -->
  style="color: red;"       <!-- inline CSS (avoid when possible) -->
  data-user-id="42"         <!-- custom data attribute -->
  hidden                    <!-- hides element -->
  tabindex="0"              <!-- keyboard navigation order -->
  title="Tooltip text"      <!-- tooltip on hover -->
></div>

<!-- Boolean attributes (present = true) -->
<input disabled/>   <!-- no value needed -->
<input required/>
<input checked/>

05

Semantic HTML

Semantic elements describe their purpose — not just their appearance. They help browsers, search engines, and screen readers understand your page structure.

<header>          <!-- site/page header -->
  <nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
  </nav>
</header>

<main>            <!-- primary content -->
  <article>       <!-- self-contained content (blog post) -->
    <h1>Post Title</h1>

    <section>     <!-- thematic grouping -->
      <p>Content here...</p>
    </section>
  </article>

  <aside>         <!-- related but secondary content -->
    <p>Sidebar content</p>
  </aside>
</main>

<footer>          <!-- page footer -->
  <p>&copy; 2025 My Site</p>
</footer>
Avoid div-soup Don't wrap everything in <div>. Use semantic elements — they communicate meaning to browsers and improve SEO and accessibility.

CSS Selectors

Selectors are patterns that tell the browser which HTML elements to style.

/* Element selector */
p { color: navy; }

/* Class selector */
.card { background: white; }

/* ID selector */
#header { font-size: 2rem; }

/* Descendant: p inside .card */
.card p { color: #555; }

/* Child: direct children only */
ul > li { list-style: square; }

/* Adjacent sibling */
h2 + p { margin-top: 0; }

/* Attribute selector */
input[type="email"] { border-color: blue; }

/* Pseudo-class */
a:hover       { color: red; }
li:first-child { font-weight: bold; }
li:nth-child(2n) { background: #f0f0f0; }

/* Pseudo-element */
p::first-line   { font-variant: small-caps; }
.card::before   { content: "★ "; }

/* Multiple selectors */
h1, h2, h3 { font-family: Georgia, serif; }

The CSS Box Model

Every HTML element is a rectangular box with four layers. Understanding this is fundamental to mastering CSS layout.

margin (outside, transparent)
border
padding (inside the border)
content
width × height
.box {
  width:   200px;
  height:  100px;

  padding: 16px;          /* inside: top right bottom left */
  border:  2px solid #333;
  margin:  24px auto;     /* outside, auto = centre horizontally */

  /* box-sizing: border-box means padding/border are */
  /* included IN the width, not added on top */
  box-sizing: border-box;
}

/* Apply border-box universally (recommended) */
* { box-sizing: border-box; }

Flexbox

Flexbox is a one-dimensional layout system — perfect for aligning items in a row or column.

.container {
  display:         flex;
  flex-direction:  row;         /* row | column | row-reverse */
  justify-content: space-between; /* main axis alignment */
  align-items:     center;      /* cross axis alignment */
  flex-wrap:       wrap;         /* allow wrapping to new line */
  gap:             16px;         /* space between items */
}

.item {
  flex:       1;                 /* grow and shrink equally */
  flex-grow:  2;                 /* grow 2× faster than siblings */
  flex-shrink: 0;                /* don't shrink */
  flex-basis: 200px;             /* starting size */
  align-self: flex-end;         /* override align-items for one item */
  order:      2;                 /* visual order (default: 0) */
}

/* Centering anything — the flex trick */
.center {
  display:         flex;
  justify-content: center;
  align-items:     center;
}

CSS Grid

CSS Grid is a two-dimensional layout system — ideal for full page layouts and complex arrangements.

.grid {
  display:               grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 equal columns */
  grid-template-rows:    auto 200px auto;
  gap:                   20px;
}

/* Responsive columns with auto-fill */
.responsive-grid {
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
}

/* Placing items */
.header {
  grid-column: 1 / -1;   /* span all columns */
  grid-row:    1 / 2;
}

.sidebar { grid-column: 1; }
.main    { grid-column: 2 / 4; }  /* span 2 columns */

/* Named areas */
.layout {
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
.header { grid-area: header; }
.main   { grid-area: main; }
14

Responsive Design

Responsive design makes websites work on all screen sizes — phones, tablets, and desktops.

/* Mobile-first: write base styles for small screens,
   then add overrides for larger screens */

.container {
  width:   100%;
  padding: 0 16px;
}

/* Tablet (min-width: 768px) */
@media (min-width: 768px) {
  .container { padding: 0 32px; }
  .grid { grid-template-columns: repeat(2, 1fr); }
}

/* Desktop (min-width: 1024px) */
@media (min-width: 1024px) {
  .container { max-width: 1200px; margin: 0 auto; }
  .grid { grid-template-columns: repeat(4, 1fr); }
}

/* Dark mode */
@media (prefers-color-scheme: dark) {
  body { background: #111; color: #eee; }
}

/* Fluid font sizing with clamp */
h1 { font-size: clamp(28px, 5vw, 72px); }
Don't forget the viewport meta tag Without <meta name="viewport" content="width=device-width, initial-scale=1.0"> in your HTML head, media queries won't work on mobile devices.

JavaScript Basics

JavaScript adds behaviour and interactivity to web pages. It runs directly in the browser and can read and modify HTML and CSS in real time.

// Variables
const name  = "Alice";     // can't reassign
let   score = 0;           // can reassign

// Functions
function greet(name) {
  return `Hello, ${name}!`;
}
const greet2 = (name) => `Hello, ${name}!`; // arrow function

// Arrays & Objects
const fruits = ["apple", "mango", "banana"];
const user   = { name: "Alice", age: 25 };

fruits.forEach(f => console.log(f));
fruits.map(f => f.toUpperCase());
fruits.filter(f => f.length > 5);

// Conditionals
if (score > 100) {
  console.log("High score!");
} else if (score > 50) {
  console.log("Good job");
} else {
  console.log("Keep trying");
}

// Loops
for (let i = 0; i < fruits.length; i++) { /* ... */ }
for (const fruit of fruits) { /* ... */ }  // cleaner

DOM Manipulation

The DOM (Document Object Model) is the browser's representation of your HTML. JavaScript can read and change it dynamically.

// Selecting elements
const el     = document.getElementById("myId");
const el2    = document.querySelector(".my-class");  // first match
const allEls = document.querySelectorAll("p");       // all <p>

// Reading & changing content
el.textContent = "New text";
el.innerHTML   = "<strong>Bold</strong>";

// Changing CSS
el.style.color = "red";
el.classList.add("active");
el.classList.remove("hidden");
el.classList.toggle("open");

// Attributes
el.setAttribute("data-id", "42");
const val = el.getAttribute("href");

// Creating & appending elements
const newDiv = document.createElement("div");
newDiv.textContent = "I'm new!";
document.body.appendChild(newDiv);

// Removing
el.remove();

Fetch API

The Fetch API lets you load data from servers without refreshing the page — essential for modern web apps.

// Basic GET request
fetch("https://api.example.com/users")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(err  => console.error(err));

// Modern async/await version (recommended)
async function getUsers() {
  try {
    const response = await fetch("https://api.example.com/users");

    if (!response.ok) throw new Error(`HTTP ${response.status}`);

    const data = await response.json();
    return data;
  } catch (err) {
    console.error("Failed:", err);
  }
}

// POST request (sending data)
async function createUser(user) {
  const res = await fetch("/api/users", {
    method:  "POST",
    headers: { "Content-Type": "application/json" },
    body:    JSON.stringify(user)
  });
  return res.json();
}
Always handle errors fetch() only rejects on network failure — a 404 or 500 response is still "resolved". Always check response.ok before using the data.
