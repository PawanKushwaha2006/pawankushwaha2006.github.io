1. What is Java?

Java is one of the world's most popular programming languages. It is used for web applications, Android apps, enterprise software, cloud systems, banking applications, games, and backend development.

Java follows the principle: Write Once, Run Anywhere (WORA).

Platform Independent

Java programs run on any operating system using JVM.

Secure

Widely used in banking and enterprise systems.

Object-Oriented

Supports classes, objects, inheritance, and abstraction.

Highly Popular

Used by millions of developers worldwide.

6. Conditional Statements

If Else

if(age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}

Switch Case

int day = 2;

switch(day) {
    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;
}

7. Loops

For Loop

for(int i = 0; i < 5; i++) {
    System.out.println(i);
}

While Loop

int i = 1;

while(i <= 5) {
    System.out.println(i);
    i++;
}

Do While Loop

do {
    System.out.println(i);
    i++;
} while(i <= 5);

9. Object-Oriented Programming

class Student {
    String name;

    void display() {
        System.out.println(name);
    }
}

public class Main {
    public static void main(String[] args) {
        Student s1 = new Student();
        s1.name = "Pawan";
        s1.display();
    }
}

Main OOP Concepts

Class

Blueprint for creating objects.

Object

Real instance of a class.

Inheritance

Acquire properties from another class.

Polymorphism

Same method behaves differently.

Encapsulation

Data hiding using private variables.

Abstraction

Show only important details.
