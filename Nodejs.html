Node.js Tutorial for Beginners 🟢

Important: Node.js browser me direct nahi chalta. Ye server-side JavaScript hai. Niche "Simulate" se basic output dekho ya "Replit" pe real Node.js chalao.

Lesson 1: Hello World

Node.js me console.log() se output dete hai. File ko node app.js se chalate hai.

console.log("Hello World");
console.log("Welcome to Node.js on CodeNix!");

Lesson 2: Variables & Functions

let aur const use karo. Functions arrow syntax se bhi likh sakte ho.

const name = "Pawan";
let age = 20;

function greet(user) {
  return `Hello ${user}!`;
}

const add = (a, b) => a + b;

console.log(greet(name));
console.log(`Age: ${age}`);
console.log(`Sum: ${add(5, 3)}`);

Lesson 3: HTTP Server

Node.js ka asli power: server banana. Ye code browser me nahi chalega, sirf Replit pe.

const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, {'Content-Type': 'text/plain'});
  res.end('Hello from Node.js Server!');
});

server.listen(3000, () => {
  console.log('Server running on port 3000');
});

Lesson 4: File System

fs module se files read/write karte hai. Browser me nahi chalega.

const fs = require('fs');

// File write
fs.writeFileSync('test.txt', 'Hello Node.js!');

// File read
const data = fs.readFileSync('test.txt', 'utf8');
console.log(data);

Lesson 5: NPM Packages

Node.js me npm install se packages lagte hai. Example: Express.js

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello Express!');
});

app.listen(3000, () => {
  console.log('Express server running');
});
