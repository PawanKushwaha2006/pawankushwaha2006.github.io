1. What is C++?

C++ is a powerful general-purpose programming language created by Bjarne Stroustrup. It is widely used in software development, game engines, operating systems, embedded systems, competitive programming, and high-performance applications.

Fast

C++ provides excellent performance and speed.

Object-Oriented

Supports classes, objects, inheritance, and polymorphism.

Popular

Used in games, browsers, operating systems, and robotics.

20. Memory Management in C++

C++ allows programmers to manually manage memory using pointers and dynamic allocation. This gives better performance and control over system resources.

Dynamic Memory Allocation

int* ptr = new int;

*ptr = 100;

cout << *ptr;

delete ptr;

Why Memory Management is Important?

  • Improves performance
  • Efficient use of RAM
  • Used in game engines and operating systems

22. Recursion

Recursion is a technique where a function calls itself. It is commonly used in algorithms and problem solving. 

int factorial(int n) {
if(n == 1)
    return 1;

return n * factorial(n - 1);

}

27. Time Complexity

Time complexity measures how fast an algorithm runs.

  • O(1) - Constant Time
  • O(log n) - Logarithmic Time
  • O(n) - Linear Time
  • O(n log n) - Efficient Sorting
  • O(n²) - Nested Loops
